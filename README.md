# Projet de gestion de tâches

### Petit projet de gestion de tâches pour m'entraîner à Next.js, le déploiement sur Vercel et la gestion de Blob sur Vercel.

## 🛠️ Technologies utilisées
- Next.js
- React
- TypeScript
- Node.js
- Prisma
- PostgreSQL
- Vercel Blob


## 🚀 Lancement local
#### Exécutez les commandes suivantes sur un terminal Bash :
- git clone https://github.com/jfl24/To-Do-List-Test.git
- cd To-Do-List-Test
- npm install
- npx prisma generate
- npm run dev
